## Цель работы
Познакомиться с синтаксисом JavaScript, базовыми алгоритмическими конструкциями (условия, циклы), функциями и логикой обработки массивов.

## Задание
Добавить на страницу скрипт (`script.js`), который реализует:
- Ввод/вывод: `prompt` (имя, массив), `alert` (приветствие, сообщение со статистикой), `console.log`.
- Условные конструкции и циклы.
- Функции для поиска максимума, фильтрации и подсчёта суммы в массиве.

### Требования варианта 20
- **Данные:** массив из 5–7 чисел — прогнозируемый годовой рост технологий/рынков в процентах в диапазоне от 0 до 100% (вводится пользователем при входе на страницу).
- **Логика:**
  - фильтрация — прогнозы роста > 20%;
  - цикл — низкие прогнозы (≤ 5%) и их доля от общего количества.
- **Функции:**
  - `findMax(arr)` — поиск максимума в массиве;
  - `filterHighGrowth(arr)` — фильтрация высоких прогнозов (> 20%);
  - `calculateSum(arr)` — подсчёт суммы элементов массива;
  - `calculateAverage(arr)` — вычисление среднего прогнозируемого роста;
  - `calculateLowGrowthStats(arr)` — подсчёт количества низких прогнозов (≤ 5%) и их доли с помощью цикла;
  - `parseForecastsInput(input)` — безопасный парсинг пользовательского ввода в массив чисел с валидацией диапазона [0; 100] и проверкой количества (от 5 до 7 чисел; при некорректном вводе выводится сообщение и подставляются данные по умолчанию).
- **Порядок работы:**
  1. `prompt` — ввод имени пользователя;
  2. `alert` — приветствие пользователя (`Привет, <имя>!`);
  3. `prompt` — пользовательский ввод массива чисел (прогнозов роста от 0 до 100%); при вводе менее 5 или более 7 корректных значений выводится сообщение об ошибке и используются значения по умолчанию;
  4. `alert` — сообщение со статистикой: `«Средний прогнозируемый рост – X%, Y прогнозов – высокие»`;
  5. `console.log` — доля низких прогнозов и их количество;
  6. Дополнительно: если максимум > 50%, вывод в консоль: `«Некоторые прогнозы выглядят очень амбициозно!»`.

## Инструкция по запуску и отладке
1. Открыть `index.html`.
2. В первом диалоговом окне `prompt` ввести своё имя (или оставить пустым — будет использовано значение по умолчанию).
3. Во всплывающем окне `alert` подтвердить приветствие.
4. Во втором окне `prompt` ввести 5–7 чисел прогнозируемого роста от 0 до 100% через запятую или пробел (например: `3, 5, 22, 35, 55`).
5. В окне `alert` отобразится итоговая статистика по среднему росту и количеству высоких прогнозов.
6. Открыть инструменты разработчика в браузере (нажать `F12` или `Ctrl + Shift + I`) и перейти на вкладку **Console** (Консоль):
   - проверить вывод доли и количества низких прогнозов;
   - проверить наличие сообщения `«Некоторые прогнозы выглядят очень амбициозно!»` (если среди введенных значений есть прогноз > 50%).
